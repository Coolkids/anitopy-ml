# 名称模板合成训练数据

## 英文主标题约定（2026-09-20）

为了贴近真实下载文件名，标题条目可使用 `title_en` 和 `title_cn`。模板中的 `$title_en` 始终标注为 `TITLE`，是作品分区键的首选来源；`$title_cn` 标注为 `TITLE_ALIAS`。因此英文标题作为主标题出现时，中文名称仍会作为可识别的别名保留。

旧的 `$title`、`$title_alias` 以及 `$title_as_title_alias_1` 保持兼容：最后一项会把旧 `title` 以 `TITLE_ALIAS` 标注，适用于只出现别名的历史模板。对于当前旧结构，`$title_en` 回退为第一个 `title_alias`，`$title_cn` 回退为 `title`；新条目仍建议显式写入 `title_en` 和 `title_cn`，避免依赖该迁移约定。

修改模板后，须先保存 `data.json`，再重新生成、去重和双隔离划分。旧标题语义生成的 V5 数据及派生报告已作废，不应混入新一轮训练或评测。

模板组可定义局部 `noise`、`noise2` 列表，并在名称中使用 `$noise`、`$noise2`。两者的渲染文本都会标注为 `NOISE`，适用于“1月新番”或检索提示等出现于标题周边、但不属于作品名称的真实噪声文本。局部词表只作用于该模板组，不需要在全局字段词表重复维护。

V6 与 V8 的合成数据、训练和冻结评测已归档并清理，关键结论见 `reports/历史训练与评测汇总.md`。当前应从 `data.json` 重新生成 V9 数据，不得复用旧分区。

`data.json` 是用户维护的合成词表和标题模板来源。工具读取其中的 `title`、技术字段词表和 `name_template`，生成带原文片段及字符级 BIO 标签的 JSONL。生成数据的 `source` 固定为 `synthetic_template`；每条记录还包含稳定的 `template_group_id`，用于隔离划分。

```powershell
uv run anitopy-ml data generate-synthetic --input data.json --output data/synthetic/模板训练数据-双隔离.jsonl --count 10000 --seed 20260918 --season-rate 0.7
uv run anitopy-ml data dedupe-synthetic --input data/synthetic/模板训练数据-双隔离.jsonl --output data/synthetic/模板训练数据-双隔离去重.jsonl
uv run anitopy-ml data split-synthetic --input data/synthetic/模板训练数据-双隔离去重.jsonl --output-dir data/synthetic/首批双隔离分区 --seed 20260918
```

生成文件旁会生成清单，其中记录样本数和 SHA-256；划分目录的 `training_manifest.json` 额外记录完整 BIO 标签表、标题条目数、模板组分配、各分区哈希与双隔离排除数量。合成数据必须与此前人工数据分开保存和统计；当前训练路线不再从 `data.csv` 或 TMDB 取样。

`--count` 是单次生成批次大小，不是训练数据总量限制。可使用不同种子持续生成批次、基于 `sample_id` 去重后追加到训练分区；当前已经生成的 10,000 条仅是首批产物。后续训练计划不再从 `data.csv` 或 TMDB 获取训练样本。

首批至 V4 的生成、训练和评测产物均已淘汰，历史结论已合并至 `reports/历史训练与评测汇总.md`。当前仅以 V6 英文主标题数据作为后续训练候选；其冻结测试尚未读取。

## 模板字段

- `$字段` 表示必填替换字段；例如 `$release_group`、`$episode_expr`、`$file_extension`。
- `&字段` 表示可选替换字段；默认 `--optional-rate 1.0`，即首批数据会填入全部模板字段。`--optional-rate` 可控制该类字段的填充比例。
- `title_alias` 会遍历当前作品的全部别名。每个别名都会依次写入 `title_alias_open`、别名文本、`title_alias_close`；别名之间再写入 `title_alias_separator`。`title_alias_begin` 仅写入一次，位于主标题和首个别名之间。使用 `"["`、`"]"` 和空 `title_alias_separator` 时会生成 `[别名一][别名二]`。包围文本和分隔符不标为实体，别名本身标为 `TITLE_ALIAS`。
- 主标题与别名不能直接拼接。模板中相邻使用 `$title`、`$title_en`、`$title_cn`、`$title_alias` 等标题占位符时，必须在模板文本中写入空格、`/` 等可见分隔符，或通过非空 `title_alias_open`、`title_alias_begin`、`title_alias_close` 提供边界。循环多个 `$title_alias` 时，必须设置非空 `title_alias_separator`，或用 `title_alias_open`、`title_alias_close` 包裹每个别名；生成器会拒绝不满足此约束的模板。
- `subtitle_language_chs` 对应中文写法，如“简繁日”；`subtitle_language_en` 对应英文缩写，如 `CHS&CHT&JP`。两者都标为 `SUBTITLE_LANGUAGE`。
- 默认 `--season-rate 0.7`：约七成样本从 `season_expr` 非空的作品中抽取，用于加强季数边界学习。可按需要传入 `0` 到 `1` 的比例；当词表中不存在含季数作品时，工具自动回退到全部标题。
- 字段词表中的 `%random(位数)` 会在每次渲染时替换为随机正整数，并补零到指定宽度。例如 `%random(2)` 会生成 `01` 至 `99`；生成的最终数值标为该字段实体，原始占位符不会进入训练文本。
- `%random_range(起点-终点)` 生成闭区间内的随机整数且不补零。例如 `S0%random_range(1-6)` 会生成 `S01` 至 `S06`。
- `%random_str($字符串来源, 最大连续字符数)` 从已渲染的来源字段中随机截取长度为 1 至上限的连续文本。例如 `%random_str($title, 5)` 从 `$title` 中随机取得最多 5 个连续字符；来源字段必须已在当前模板渲染上下文中定义。
- 模板组可定义局部 `release_version` 词表，并在名称中使用 `$release_version`；其最终文本标为 `RELEASE_VERSION`。例如 `v%random(1)` 会生成 `v1` 至 `v9`，可与集数直接相连生成 `09v2`。
- `disable` 是模板组的禁用条件列表。`%len($title_alias) > 2` 表示当前标题条目的非空别名数量大于 2 时，不使用该模板组。当前仅支持 `%len($数组字段)` 与整数的 `>`、`>=`、`<`、`<=`、`==`、`!=` 比较；条件成立即禁用，多个条件中任一成立即禁用。
- `$title_alias[1]` 表示第一个非空别名，索引从 1 开始；仅该别名被标为 `TITLE_ALIAS`。`exclude_title_season_expr: true` 会只抽取标题自身没有季数表达的条目，并使用模板组内的 `season_expr` 词表填充 `$season_expr`。模板组内的 `$random_month` 从同组 `random_month` 词表中取值，作为未标注的格式文本。

其余字段按固定映射生成片段：`release_group` → `RELEASE_GROUP`、`release_version` → `RELEASE_VERSION`、`source` → `SOURCE`、`resolution` → `RESOLUTION`、`video_term` → `VIDEO_TERM`、`audio_term` → `AUDIO_TERM`、`bit_depth` → `BIT_DEPTH`、`subtitle_mode` → `SUBTITLE_MODE`、`episode_expr` → `EPISODE_EXPR`、`episode_count_expr` → `EPISODE_COUNT_EXPR`、`file_extension` → `FILE_EXTENSION`。标题条目中明确列出的 `season_expr` 会从标题或别名中拆分并标为 `SEASON_EXPR`，以避免与标题片段重叠。

## 使用边界

合成文本适合帮助模型学习字段格式、括号、分隔符及中英文字幕写法，不能证明模型能识别真实发布标题。划分器会分别稳定分配标题条目和模板组，只导出二者归属相同分区的样本，因此训练、验证和测试不会共享任一标题条目或模板组。指标只能表述为模板分布内评测。
