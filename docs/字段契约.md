# 字段契约

结构化结果以 `ParseResult` 为顶层对象，字段定义以 [task.md](../task.md) 第4节为准。本文件说明当前代码已经固定的边界。

- `raw_text` 永远保存用户输入的原始标题；不会被外部作品库名称替换。
- `extracted` 只保存标题原文可支持的提取与规范化结果；`catalog` 只保存外部作品库关联。
- `Span` 的 `start`、`end` 使用 Python Unicode 码点的左闭右开区间，且 `raw_text[start:end]` 必须等于 `text`。
- `Evidence` 保存原文片段、来源、版本和置信度；未校准的分数必须将 `calibrated` 设为 `false`。
- 标题规范化输出 `normalized_text` 与 `model_text`。每个输出字符都有原文区间映射；网址和常见 BBCode 仅从 `model_text` 隐藏，原文和规范化视图仍保留。
- 超过模型长度的标题通过 `make_model_windows()` 生成可重叠窗口。窗口记录模型文本全局区间和最小原文覆盖区间；训练阶段会在词元化后复用相同覆盖语义。
- `special_type` 仅记录标题中明确出现的 OVA、OAD、TVSP、NCOP、NCED 或 SP；它不会自动映射为数据库第0季。
- `DataLineage.training_allowed` 为 `false` 时，训练导出必须拒绝该样本。
- `AnnotationRecord` 由样本、原文片段、结构字段、审核元数据和数据来源组成；当前BIO模式不允许片段重叠。
- `ModelManifest` 固定模型、分词器、Schema、规范化版本、训练数据清单哈希和标签顺序。标签定义由 `configs/标签定义.json` 管理。

当前可用片段类型固定在 `schemas.py` 的 `VALID_SPAN_LABELS`。新增标签、字段或破坏性变更必须提高Schema版本，并添加迁移与回归测试。
