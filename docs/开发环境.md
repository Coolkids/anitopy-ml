# 开发环境

项目基础包使用 Python 3.12 或更高版本。建议使用单独的 `.venv`，不要覆盖已有的 `venv`。

```powershell
uv venv --python 3.12 .venv
uv sync --extra dev
uv run anitopy-ml doctor
uv run python -m unittest discover -s tests -t .
```

`doctor` 只报告运行环境和可选组件是否已安装，不会读取、显示或保存任何访问凭证。训练、TMDB、审核界面和HTTP服务的依赖将在对应实现步骤中添加并锁定。

## 导入标题与生成旧解析基线

以下命令只在本地读取CSV和冻结的旧解析器。导入会保留原文、源文件哈希和行号；清单保存数据版本、重复统计和格式统计。批量基线以样本ID、原文哈希和源行号关联结果，不会改写原始CSV。

```powershell
uv run anitopy-ml data ingest --input data.csv --output data/raw/titles.jsonl --manifest data/raw/titles.manifest.json
uv run anitopy-ml baseline --legacy-source E:\Code\anitopy --input data/raw/titles.jsonl --output reports/旧解析结果.jsonl
```

未指定 `baseline --input` 时，该命令仍运行旧项目自带夹具的兼容性比对。生成的原始数据、清单和报告均为本地数据，已被 `.gitignore` 忽略。

## 按作品组划分数据

划分仅自动合并保守标题键相同的样本。人工在审核页面设置的作品组ID优先；每个作品组使用固定种子只会落入一个分区。报告保存源数据哈希、种子、分区统计和自动合并数量。

```powershell
uv run anitopy-ml data split --input data/raw/titles.jsonl --output data/splits/assignments.jsonl --report reports/数据划分报告.json --seed 20260917 --database data/annotations/labels.sqlite
```

该命令在写出前检查作品组是否跨分区。近重复、别名和疑似同组样本仍需后续复核，不能把保守自动分组视为人工确认。

可生成去除前导发布组标识后的疑似同组复核队列。此命令不修改既有作品组或分区：

```powershell
uv run anitopy-ml data group-audit --input data/raw/titles.jsonl --output reports/疑似作品组.jsonl --report reports/疑似作品组报告.json --seed 20260917 --database data/annotations/labels.sqlite
```

默认只输出保守键精确候选及相似度至少为 `0.98` 的前500条近重复候选。离线分析可通过 `--similarity-threshold` 和 `--max-similarity-candidates` 调整范围；调低阈值前应评估人工复核容量。
