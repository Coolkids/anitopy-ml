# 标注规范

当前标注库以SQLite保存，每次修改生成递增版本并保留审计记录。规则预标注的层级为 `weak`、状态为 `pending`，其 `training_allowed` 固定为 `false`；人工审核后才能提升为金标或银标。

审核时使用原始标题选择片段。片段偏移以Python Unicode码点计数，左闭右开；同一条记录使用扁平BIO标签，因此片段不得重叠。无法确认的区域应保留为未标注，不能直接标为 `O`。

当前命令：

```powershell
uv run anitopy-ml annotate seed --input data/raw/titles.jsonl --database data/annotations/labels.sqlite --limit 100
```

该命令只生成待审核建议，不会访问TMDB，不会修改原始CSV，也不会将结果自动加入训练集。

列出待审核样本：

```powershell
uv run anitopy-ml annotate review --database data/annotations/labels.sqlite --list
```

审核通过会创建新版本、写入审核人员和审计事件，并将数据来源增加为 `human`；审核前应由人员实际核对标题片段和结构字段。审核拒绝不会删除原有弱标注，也不会允许训练。

人工审核网页已移除。当前训练由 `data.json` 模板自动生成，不再依赖人工审核页面。实际标题应使用本地模型验证页面检查，启动方式和核对重点见 [模型验证页面](模型验证页面.md)。

每轮审核后生成质量报告，报告只统计各样本最新版本，并区分已接受且允许训练的样本与待审、拒绝、复核样本：

```powershell
uv run anitopy-ml annotate report --database data/annotations/labels.sqlite --output reports/金标质量报告.md
```

报告达到首批300条前仅用于完善规范和审核流程，不得据此宣称模型已完成训练或效果提升。
