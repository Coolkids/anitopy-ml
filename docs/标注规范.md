# 标注规范

当前标注库以SQLite保存，每次修改生成递增版本并保留审计记录。规则预标注的层级为 `weak`、状态为 `pending`，其 `training_allowed` 固定为 `false`；人工审核后才能提升为金标或银标。

审核时使用原始标题选择片段。片段偏移以Python Unicode码点计数，左闭右开；同一条记录使用扁平BIO标签，因此片段不得重叠。无法确认的区域应保留为未标注，不能直接标为 `O`。

当前命令：

```powershell
uv run anitopy-ml annotate seed --input data/raw/titles.jsonl --database data/annotations/labels.sqlite --limit 100
```

该命令只生成待审核建议，不会访问TMDB，不会修改原始CSV，也不会将结果自动加入训练集。

列出待审核样本：

```powershell
uv run anitopy-ml annotate review --database data/annotations/labels.sqlite --list
```

审核通过会创建新版本、写入审核人员和审计事件，并将数据来源增加为 `human`；审核前应由人员实际核对标题片段和结构字段。审核拒绝不会删除原有弱标注，也不会允许训练。

启动本地审核页面：

```powershell
uv run python tools/review_app.py --database data/annotations/labels.sqlite
```

页面仅监听 `127.0.0.1:8765`。可在原始标题中拖选片段、切换标签、编辑季集字段，并将浏览器UTF-16偏移转换为后端使用的Unicode码点偏移；下方JSON仍可用于审查完整结构。

审核页面默认尝试加载 `artifacts/runs/当前金标连通性` 中的本地模型，并在样本页显示“模型建议”。也可明确指定模型目录：

```powershell
uv run python tools/review_app.py --database data/annotations/labels.sqlite --model artifacts/runs/当前金标连通性
```

模型建议与当前标注草稿分开显示，使用中文标签。点击“将模型建议载入编辑草稿”只会覆盖浏览器中尚未保存的片段和结构字段；必须由审核人员检查、修改并提交保存，才会生成新的待复核版本。模型预测不会自动写入SQLite、不会自动审核通过，也不会自动获得训练许可。当前字符模型仅有小样本金标，建议重点核对主标题、数字和技术字段后再保存。

“撤销未保存编辑”只恢复当前页面打开时的版本；保存会创建新版本，旧版本和审计记录不会被覆盖。无法判断会清空片段并把整条标题保留为未标注区域，进入“待复核”队列且不可用于训练。队列可筛选待审核或待复核状态，且只显示每个样本的最新版本。

页面还提供本地人工作品组ID。它用于后续数据划分，保存时记录操作人和审计事件；候选面板当前是明确标示的模拟入口，不读取或展示外部作品库数据。

审核首页默认使用“每组一个代表”视图：按宽松标题键把相似待审标题归在一起，并优先显示标题更短的代表样本；页面会标明该组待审数量。该视图只筛选显示，不会删除、拒绝或修改同组的其他弱标注。需要逐条检查时，可切换到“查看全部待审样本”。

每轮审核后生成质量报告，报告只统计各样本最新版本，并区分已接受且允许训练的样本与待审、拒绝、复核样本：

```powershell
uv run anitopy-ml annotate report --database data/annotations/labels.sqlite --output reports/金标质量报告.md
```

报告达到首批300条前仅用于完善规范和审核流程，不得据此宣称模型已完成训练或效果提升。
