# 模型实际验证页面

人工标注网页已移除。当前页面用于验证本地模型对实际媒体标题的解析表现，不读取或写入SQLite标注库，也不保存输入的名称。

启动命令：

```powershell
uv run python tools/model_verify_app.py --model artifacts/runs/V11_template_coverage_warm_start_seed1 --device cuda
```

打开 `http://127.0.0.1:8765`，粘贴一个媒体标题并点击“开始识别”。页面按以下优先级展示结果：

1. 主标题；
2. 作品别名；
3. 季数；
4. 集数、集数范围和声明总集数。

主标题与别名相连时，可以按两者组合后的整体边界判断是否正确。发布组、发布版本、片源、分辨率、音视频编码和字幕字段均显示在“辅助字段”中，不作为当前模型验证的核心指标。

页面同时列出模型返回的原文证据、Unicode位置、解析状态、中文提示和完整JSON，方便定位具体边界或字段分类问题。
