# 训练数据导出

训练导出只读取标注库中的最新版本，并要求样本同时满足：审核状态为 `accepted`、`training_allowed` 为 `true`、没有未标注区域，且存在冻结分区。任一条件不满足时样本会被排除并写入清单统计，不会把未知区域写成 `O`。

```powershell
uv run anitopy-ml annotate export-training --database data/annotations/labels.sqlite --splits data/splits/assignments.jsonl --output-dir data/processed/首批训练数据
```

输出目录包含 `train.jsonl`、`validation.jsonl`、`test.jsonl` 和 `training_manifest.json`。每条JSONL记录使用原始标题的 Unicode 字符序列和对应 BIO 标签；后续 fast tokenizer 对齐阶段必须依据该字符位置生成词元标签，不能移动人工片段边界。

清单记录每个分区的样本数、文件哈希、完整标签顺序和排除原因。导出成功仅表示数据格式与来源校验通过；样本量达到首批目标前不得开始正式训练或对外宣称模型能力。

导出会将冻结分区中的作品组与标注库最新的人工作品组覆盖合并检查。同一有效作品组若同时位于训练、验证或测试的不同分区，命令会拒绝导出并提示先重新执行 `data split`。这项检查防止人工合并相似标题后把同一作品泄漏到评测分区。

## 分词器对齐与长标题

训练器应将 fast tokenizer 返回的偏移映射传给 `align_bio_offsets()`。特殊词元、填充词元和跨越人工实体边界的词元标签均为忽略值 `-100`，并会返回中文原因；训练器不得移动人工边界来消除这些问题。

超过单窗口长度的标题使用 `make_character_windows()` 生成字符窗口。窗口保存原文全局偏移；重叠字符只在首次出现的窗口计算损失，后续窗口对应位置的损失掩码为关闭。

动态批处理使用 `dynamic_pad()`。填充位置的标签固定为 `-100`，注意力和损失掩码固定为关闭。无法对齐的记录通过 `write_alignment_issues()` 写入独立 JSONL，记录样本ID和原因，供人工修订后重新导出。

训练集可使用 `augment_train_whitespace()` 增加既有空白后的空白字符。该增强会重建字符序列和 BIO 标签，只接受 `train` 分区，并在输出中保留 `parent_sample_id`、`work_group_id` 和增强类型；验证、测试样本会被拒绝。

模型输出应使用 `constrained_bio_decode()` 执行受 BIO 转移约束的 Viterbi 解码，避免序列从 `I-` 标签开头或切换到不相容实体内部。评测使用 `entity_metrics()`，只有实体类型和起止边界完全一致才计为正确。

## 模型依赖与离线加载

模型配置固定为 `FacebookAI/xlm-roberta-base` 和项目 BIO 标签顺序。安装训练依赖时执行：

```powershell
uv sync --extra train
```

`create_extractor_model()` 默认使用本地文件加载，缺少权重时会失败而不会联网下载。模型包含 BIO 抽取头和三类媒体类型头。

训练损失使用 `masked_multitask_loss()`。只有对齐成功且损失掩码开启的位置参与 BIO 交叉熵；媒体类型标签可缺失，缺失位置不参与媒体类型损失。

训练器配置位于 `configs/抽取训练.json`。训练循环支持梯度累积和梯度裁剪；`save_torch_training_state()` 会保存模型、优化器、调度器和 Torch 随机状态，`checkpoint_metadata.json` 则保存训练数据清单哈希和训练进度。恢复训练时必须同时验证两类状态。

## 当前金标连通性训练

在开始正式 XLM-R 训练前，可用当前已接受金标运行字符级连通性训练，确认导出的 BIO 数据、标签数和反向传播链路能够正常工作：

```powershell
.\.venv\Scripts\python.exe tools/smoke_train.py --data-dir data/processed/首批训练数据 --output-dir artifacts/runs/当前金标连通性 --epochs 8 --batch-size 8
```

该脚本会自动选择 CUDA；当前环境未安装 CUDA 版 Torch 时使用 CPU。它在 `训练报告.json` 中记录设备、样本数、每轮训练损失和验证字符准确率，并保存 `character_tagger.pt`。当前运行使用 58 条训练样本与 5 条验证样本，8 轮训练损失从 3.745 降至 2.577。

训练结束后，脚本还会写入 `training_state.pt` 与 `checkpoint_metadata.json`。它会将模型和优化器恢复到新建对象，在同一输入上逐元素比较恢复前后的输出，并把结果写入报告的 `检查点恢复自检通过` 字段。本次自检已通过；元数据记录训练完成于第 8 轮、共 64 个优化步骤和训练数据清单哈希。

这项训练只验证数据和训练链路连通，字符级模型与 2 条验证样本均不能代表 XLM-R 的实体级识别能力。正式效果评测仍须使用独立测试集、`entity_metrics()` 和达到计划数量的金标数据。

## 下一轮 V9 标题别名边界与噪声字段训练

V6 与 V8 的冻结测试均已消费。V9 基于修正后的 `title_alias_begin`、逐别名包裹语义、`noise2` 与 `%random_str` 重新生成 180,000 条原始样本，去重后再进行标题条目和模板组双隔离。训练阶段只读取 `train.jsonl` 和 `validation.jsonl`，不得读取 `test.jsonl`。

先在项目根目录生成数据：

```powershell
$ErrorActionPreference = "Stop"

uv run anitopy-ml data generate-synthetic `
  --input data.json `
  --output data\synthetic\V9_alias_boundary_noise_raw.jsonl `
  --count 180000 `
  --seed 20260924 `
  --season-rate 0.7

uv run anitopy-ml data dedupe-synthetic `
  --input data\synthetic\V9_alias_boundary_noise_raw.jsonl `
  --output data\synthetic\V9_alias_boundary_noise_deduplicated.jsonl

uv run anitopy-ml data audit-synthetic `
  --input data\synthetic\V9_alias_boundary_noise_deduplicated.jsonl `
  --output reports\V9_alias_boundary_noise_coverage.json

uv run anitopy-ml data split-synthetic `
  --input data\synthetic\V9_alias_boundary_noise_deduplicated.jsonl `
  --output-dir data\synthetic\V9_alias_boundary_noise_split `
  --seed 20260924
```

确认覆盖报告和 `training_manifest.json` 后，用以下单个 PowerShell 命令块顺序训练三个固定种子。每个种子完成后才开始下一个；任一次失败会立刻停止，避免把不完整结果误作复测完成。

```powershell
$runs = @(
  @("V9_alias_boundary_noise_seed1", 20260924),
  @("V9_alias_boundary_noise_seed2", 20260925),
  @("V9_alias_boundary_noise_seed3", 20260926)
)

foreach ($run in $runs) {
  uv run anitopy-ml train extractor `
    --data-dir data\synthetic\V9_alias_boundary_noise_split `
    --output-dir ("artifacts\runs\" + $run[0]) `
    --config configs\V9_alias_boundary_noise_training.json `
    --epochs 1 `
    --batch-size 2 `
    --max-length 256 `
    --device cuda `
    --seed $run[1]

  if ($LASTEXITCODE -ne 0) {
    exit $LASTEXITCODE
  }
}
```

V9 三种子训练已完成，验证实体 F1 为 `0.9711`、`0.9792`、`0.9692`，均值为 `0.9731`，样本标准差为 `0.0053`。种子 2 固定为唯一校准候选；详见 `reports/V9标题别名边界与噪声字段固定种子稳定性报告.md`。冻结测试尚未读取。

传入 `--augment-whitespace` 时，训练器仅对 `train.jsonl` 追加“既有空白后插入一个空白”的增强样本；验证与测试分区不会被修改。训练报告会分别记录原始训练样本数和增强样本数，便于与未增强实验比较。
