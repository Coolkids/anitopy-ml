# 离线调用指南

当前可以加载本地字符连通性模型或已训练的 XLM-R 检查点，完成离线 BIO 解码、原文证据回填和批量错误隔离。旧实验均未达到发布条件，历史结论见 `reports/历史训练与评测汇总.md`；结果只适用于标题与模板组双隔离的合成数据，不能用于判断真实发布标题效果。

## Python 单条调用

```python
from anitopy_ml.api import MediaParser

parser = MediaParser.from_pretrained(
    "artifacts/runs/当前金标连通性",
    device="auto",
)
result = parser.parse("示例作品 S01E02 1080p")

print(result.extracted.title)
print(result.extracted.seasons)
print(result.model_dump())
```

`from_pretrained()` 会识别目录中的 `character_tagger.pt` 或 XLM-R 的 `best_model.pt`。XLM-R 检查点还会读取同目录 `tokenizer/`，并使用本地缓存的基础模型；默认不联网下载任何文件。若模型目录有与权重哈希匹配的 `calibration.json`，会自动加载字段置信度校准器。`device="auto"` 会在 CUDA 可用时选择 CUDA，否则使用 CPU；指定 `device="cuda"` 但 CUDA 不可用时会给出中文错误。

`parse()` 返回 `ParseResult`。其中 `raw_text` 始终是原始输入，`evidence` 中的片段使用原始字符串的 Unicode 码点位置。已校准字段的 `confidence` 是验证集经验校准值且 `calibrated=true`；样本不足、未预测或非模型来源的字段保持原始分数或空值，并明确标为 `false`。

模型未识别主标题时，结果的 `status` 为 `partial`，但季集、分辨率等明确格式字段仍会由约束层返回。不要把 `partial` 结果或小样本模型输出当作可发布的识别结论。

## 批量调用

```python
titles = ["示例作品 S01E02", "", "示例电影 1080p"]
results = parser.parse_batch(titles, on_error="record")

for item in results:
    if isinstance(item, dict):
        print("失败：", item["raw_text"], item["warnings"])
    else:
        print(item.raw_text, item.status)
```

批量结果与输入顺序一致。`on_error="record"` 会将单条错误记录为包含 `raw_text`、`status` 和中文 `warnings` 的字典，并继续处理后续标题；`on_error="raise"` 则在第一条错误时抛出异常。

## 命令行调用

```powershell
# 输出单条JSON结果到终端
uv run anitopy-ml parse "示例作品 S01E02 1080p" --model artifacts/runs/当前金标连通性

# 从CSV的record_title列读取标题，按原顺序写入JSONL
uv run anitopy-ml batch --input data.csv --column record_title --model artifacts/runs/当前金标连通性 --output reports/批量解析.jsonl --on-error record
```

`batch` 不会联网。若 CSV 缺少指定列，命令会返回中文错误；单条标题为空等可预期错误在 `--on-error record` 下会写入对应 JSONL 行，其他标题继续处理。

## 校准置信度

候选模型固定后，只能使用验证集生成校准文件，不能读取冻结测试集：

```powershell
uv run anitopy-ml calibrate --model artifacts/runs/扩容V6英文主标题种子2 --validation data/synthetic/扩容V6英文主标题双隔离分区/validation.jsonl --output artifacts/runs/扩容V6英文主标题种子2/calibration.json --device cuda
```

校准结果会写入各字段的样本数、正确数、分桶经验置信度、样本不足的未校准字段和覆盖率—错误率曲线。校准文件保存 `best_model.pt` 的 SHA256；权重变更后加载会拒绝不匹配的文件。`--minimum-samples` 默认为 20，可提高该值来减少校准字段范围，但不得把未校准的 softmax 分数描述为正确概率。

接受策略按字段选择阈值，避免全局平均错误率掩盖标题和别名的风险。V6 的阈值与复核字段必须由 V6 验证集重新确定，不能继承旧 V4 策略。策略文件会自动加载；需要复核或未校准字段仍会返回原文证据，但会追加中文提示，主标题未满足条件时解析状态为 `partial`。

```powershell
uv run anitopy-ml calibration-policy --calibration artifacts/runs/扩容V6英文主标题种子2/calibration.json --output artifacts/runs/扩容V6英文主标题种子2/acceptance_policy.json --maximum-error-rate 0.05
```

## 冻结测试评测

校准和接受策略固定后，才可读取一次冻结测试分区：

```powershell
uv run anitopy-ml evaluate --model artifacts/runs/扩容V6英文主标题种子2 --test data/synthetic/扩容V6英文主标题双隔离分区/test.jsonl --output reports/模型评测/扩容V6英文主标题冻结测试.json --device cuda
```

报告包含严格实体 F1、字段完全正确率、整条严格完全正确率、自动接收/复核/未校准字段统计及最多 100 条误差样本。V6 命令已执行且冻结测试已经消费，不得重复运行；后续版本必须使用新的模型目录和未读取的测试分区。

## 当前范围

当前接口尚未提供作品关联、滑窗合并或旧 Anitopy 兼容字典。XLM-R 单窗口长度为 256 个词元；超长标题会返回中文警告，后续滑窗合并完成前不应将其结果用于完整解析。模型目录没有有效 `calibration.json` 时，模型置信度不会被标记为已校准。
